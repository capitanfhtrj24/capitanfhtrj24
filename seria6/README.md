# Космофлот, шестая серия 

## Совещание на корабле

Звучит тревога, офицеру докладывают, на одной из баз ишнаитов собираются сделать жертвоприношения. Офицер говорит - оцепите район, наша группа должна быть в постоянной готовности вокруг их базы, готовится перекрыть район и ни кого ни впускать ни выпускать, для прикрытия одеться в форму местной службы безопасности. При угрозе людям готовится в любой момент ликвидировать угрозу с орбиты. Ждем их гостей и максимально все документируем видео.

## Место экипировки экипажа

Воины одеваются, инженер говорит это специальные очки в виде стандартной экипировки службы безопасности, вот основные функции, обычное зрение, автоматическое видение в темноте, просмотр электрической активности. Режимы могут переключатся по движению глаз, и показывать обычное зрение или ночное с на одной половине, электрическая активность в другой половине, так же есть картинка в картинке.
