# Космофлот, шестая серия 

## Совещание на корабле

Звучит тревога, офицеру докладывают, на одной из баз ишнаитов собираются сделать жертвоприношения. Офицер говорит - оцепите район, наша группа должна быть в постоянной готовности вокруг их базы, готовится перекрыть район и ни кого ни впускать ни выпускать, для прикрытия одеться в форму местной службы безопасности.
